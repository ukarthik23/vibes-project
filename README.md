# Vibes Project

A little corner of the internet for Hack Club DPSN, made for [Vibes](https://vibes.hackclub.com/).

Called it **The Build Room**. Soft shadows, Hack Club red, a few project ideas, and the people behind the club. Basically: what if a club website felt like buttons you wanted to press?

[Open the site](https://ukarthik23.github.io/vibes-project/) · [Our club](https://hack-club-dpsn.vercel.app/)

## What's in here

Just `index.html` — HTML and CSS, all in one file. No framework, no install, no backend. Open it in a browser and you're good.

The project cards are ideas to try, not a list of things we've shipped. The page itself is intentionally static.

## Make it yours

The colours and shadows live in `:root` near the top of the CSS. Change those, mess with the cards, break something, fix it. That's half the fun.

Built with help from ChatGPT for the Vibes project.
